# knowledge

Stable, human-managed knowledge goes here.

Use this directory for information that should be shared by server Hermes and main-PC Hermes via Git:

- environment notes
- project decisions
- operating rules
- reusable context that should not depend on a single chat session

Do not put secrets, tokens, private logs, raw conversation dumps, or large personal diaries here.

Conversation-derived long-term context should go to OpenViking, not Git.
